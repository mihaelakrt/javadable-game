Code puzzle / Draw it with loops+Javadable

Three hundred pictures.One method.Fewer characters.

Every level shows a picture. You write Java that paints the same picture on the grid, in as few characters as you can. Your code is compiled while you play, by the real compiler.

Download the jar Source on GitHub

The whole language is one method

for (int x = 0; x < W; x++) {
    p(x, 2, "cyan");
}

p(x, y, colour) paints a cell, a fourth argument writes a mark or an emoji on it, and W and H are the size of the grid. Everything else is ordinary Java: loops, conditions, arrays, Math.

What is in it

300 levels

Thirty drawn by hand, the rest generated, each one with a solution that is known to exist, which is how the budget is set.

A new daily

Every day the game makes up a puzzle nobody has seen, the same one for everyone, and keeps your streak.

24 colours and marks

Click a colour and it lands in your code. Flip the bar over for stars, hearts and emoji to write on the cells.

Studio

Draw with the mouse and the game writes the code back to you, folding runs of cells into loops.

A profile

A name and a badge of your own, your rank, and every level with its stars and your best character count against par.

No dependencies

Pure Java Swing. Every pixel on screen is drawn by hand with Java2D.

Playing it

Download the jar from the release and start it with a JDK, not just a JRE, because the game compiles your code while it runs.

java -jar javadable-1.1.jar

Or clone the repository and double click Javadable.bat on Windows, which builds it and starts it.
